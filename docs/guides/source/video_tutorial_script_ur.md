# Budget Pro — Complete Video Tutorial Script (Urdu / Roman Urdu)

**App:** Budget Pro v2.1  
**Developer:** Saleem Shalwani  
**Use:** Mobile screen recording + voice-over  
**Total time:** 18–25 minutes (aap ki speed par depend karta hai)

---

## Recording tips (pehle parh lein)

1. Phone par **Screen Recorder** on karein (sound + mic dono).
2. Pehle app **fresh install** karein ya demo profile use karein taake real data na dikhe.
3. Har scene ke baad 1–2 second ruk jayein taake viewer samajh sake.
4. Neeche **[ACTION]** lines = screen par kya tap karna hai.
5. Example amounts: Salary 50,000 | Food 500 | Transfer 10,000

---

## SCENE 1 — Introduction (1 min)

**Script:**

> Assalam o Alaikum! Main aap ko **Budget Pro** app ka complete tutorial dikhane wala hoon.
> Yeh app aap ke paison ko track karti hai — income, expense, transfer, reports, investments, diary, notes aur secure vault sab ek jagah.
> Yeh app bank se paise nahi leti — sirf aap jo likhte hain woh save karti hai.
> Chaliye shuru karte hain bilkul zero se.

**[ACTION]** App icon tap karein → Budget Pro kholein.

---

## SCENE 2 — App ke 7 tabs samjhein (1 min)

**Script:**

> Neeche **7 tabs** hain. In ka naam yaad rakhein:
> **Wallet** — rozana paise in/out  
> **Reports** — charts aur statements  
> **Portfolio** — shares, gold, crypto waghera  
> **Diary** — personal journal  
> **Notes** — quick notes aur useful links  
> **Vault** — passwords aur cards safe  
> **Settings** — accounts, categories, backup, security  
> Upar **profile switch**, **bell** (budget alerts), **search** (Wallet par), aur **exit** button hai.

**[ACTION]** Har tab par ek ek second tap karke dikhayein, phir **Settings** par jayein.

## SCENE 3 — Naya Profile banana (1.5 min)

**Script:**

> Pehle **profile** set karte hain. Profile alag alag hisson ke liye hoti hai — jaise Personal, Shop, ya Family.
> Har profile ka apna alag data hota hai — mix nahi hota.

**[ACTION]** Upar **Switch profile** icon dabayein.

**Script (continue):**

> Naya naam likhein, maslan **Personal**, phir **Create and switch** dabayein.
> Ab title bar par **Personal** likha aayega.

**[ACTION]** Profile create karein → wapas main screen.

---

## SCENE 4 — Currency set karna (1 min)

**Script:**

> Pehle currency set karte hain taake amounts sahi symbol mein dikhein.
> Default **PKR** hai. Aap USD, AED, SAR waghera bhi choose kar sakte hain.
> Yeh sirf **display** change karta hai — purane numbers convert nahi hote.

**[ACTION]** Settings → **Preferences** → **Currency** → PKR select (ya apni marzi ki) → back.

---

## SCENE 5 — Account banana (2 min) ⭐ IMPORTANT

**Script:**

> Ab **Account** banate hain. Account matlab paise kahan rakhe hain — Cash, Bank, JazzCash, EasyPaisa.
> Shuru mein sirf ek **Cash** account kaafi hai.

**[ACTION]** Settings → scroll **Accounts & Categories** → **Add New Account**.

**Script (continue):**

> Name likhein: **Cash**  
> Opening balance = aaj kitne paise hain — maslan **25000**  
> Save karein.
> Ab doosra account bhi bana sakte hain — **Bank**, opening **100000**.

**[ACTION]** Do accounts save karein → list mein dikhein.

## SCENE 6 — Category aur Sub-Category (3 min) ⭐ IMPORTANT

**Script:**

> Reports aur budget alerts isi par depend karte hain.

**[ACTION]** **Add Transaction Category** (ya Add Category) dabayein.

**Script (continue):**

> Pehli category: **Food**

> Sub-categories add karein: **Groceries**, **Restaurants**, **Snacks**

> Doosri category: **Salary** — budget 0 ya koi bhi  
> Teesri: **Transport** — sub: **Fuel**, **Taxi**

**[ACTION]** 3 categories save karein → list scroll karke dikhayein.

## SCENE 16 — Reports: Category-wise + Opening (2.5 min) ⭐

**Script:**

> Ab sirf ek category ki report — maslan **Food**.
> Date range select karein — maslan **1 April se 19 June**.
> **Cat Open** = period se pehle (31 March tak) category ka balance  
> **Cat In / Cat Out / Cat Net** = sirf is period ka  
> **Cat Close** = Open + Net

**[ACTION]** Category dropdown → **Food** → date range set → summary card dikhayein  
**[ACTION]** Sub-category dropdown → **Groceries** filter (agar hai)

**Script (continue):**

> Neeche **Category & sub-category report** section har category ke andar sub breakdown dikhata hai.
